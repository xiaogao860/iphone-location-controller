# iPhone 定位控制器

双击同目录的「定位控制器.app」即可使用。此版本针对当前 Apple Silicon Mac 构建，使用本机 /usr/bin/python3（当前由 Apple Command Line Tools 提供）；Python 第三方依赖已包含在 app 内，不依赖工作目录的虚拟环境。不是跨机器通用安装包。

## 使用

1. USB 连接并解锁 iPhone，信任电脑，开启开发者模式。
2. 默认位置为天安门广场，地图坐标 39.904123 / 116.397682。启动不再请求 Mac 定位。可以地图选点或输入坐标更改。
3. 点击「连接手机」，等待连接完成。
4. 输入速度，单位 km/h，无上限，须为有效非负数。点击「开始 WASD 控制」。
5. W 北、S 南、A 西、D 东；按住移动，松开停止，可同时按两个方向键。斜向速度与单方向相同。
6. 速度可随时编辑。输入结束后点击窗口空白区域，使输入框失去焦点，再按方向键。中文输入法不影响按键方向，使用物理键位。
7. 「暂停移动」保留模拟坐标；「恢复真实定位 / 断开」清除模拟坐标并断开。正常关闭窗口也会请求清除定位。

窗口失去焦点时会清空方向键状态，回到窗口后需要重新按键。控制期间无方向输入时每秒重发当前位置；有方向输入时最多每秒更新 4 次。界面“已发送位置”表示手机开发服务接受了设置指令，最终定位效果请在苹果地图和目标应用检查。

## 恢复和异常

使用后点击「恢复真实定位 / 断开」，再在苹果地图点击当前位置确认恢复。拔线、应用崩溃、强制结束或手机锁定可能使清除请求失败。此时重新连接并点击恢复；仍异常可重启 iPhone。应用不会自动关闭开发者模式。

连接准备首次可能下载开发支持组件，需要联网；应用使用用户态开发连接，不修改 Mac DNS、路由或代理设置。一次只连接一部 iPhone。

## 验证范围

当前设备：macOS 26.6，iPhone iOS 26.5.1。固定坐标模拟已经在苹果地图实机验证。此应用的真实设备连接、坐标发送、恢复命令与界面显示已验证；运动轨迹、成绩、后台运行及其他设备系统版本未验证。

## 源码与依赖

「源码/main.swift」为 AppKit 原生界面；「源码/backend.py」通过 pymobiledevice3 11.27.2 操作开发定位服务。依赖及其许可文件位于 app 的 Contents/Resources/python 中。pymobiledevice3 使用 GPL-3.0，项目源代码：https://github.com/doronz88/pymobiledevice3 。本应用源代码以 GPL-3.0 提供；本地临时签名，未做 Apple 公证。

编译界面：

```sh
xcrun swiftc 源码/main.swift 源码/RouteMotion.swift 源码/TrackGeometry.swift -o 定位控制器.app/Contents/MacOS/LocationController -framework Cocoa -framework MapKit
codesign --force --deep --sign - 定位控制器.app
```

## 路线跑步（1.2）

选择「绘制路线」，在地图依次点击途经点。路线首点为绘制模式下第一次点击的位置，不会自动加入 Mac 当前位置或 WASD 起点。蓝线按选点顺序直线连接，不会自动沿道路规划，因此请自己选好转弯点。可撤销末点、清空路线。至少两点后，连接手机并点击「开始路线跑步」；共享速度输入框，速度无上限，路线运行须大于零。

路线自动运行期间切换窗口仍会继续。点击同一按钮暂停、继续，关闭「循环路线」时到终点停止并保留模拟位置；启用循环时从最后点重新开始，想避免跳回起点请把最后点选在首点附近。恢复真实定位使用恢复按钮。

路线的跨点推进、停止、循环、重复点和跨经线计算已经过自动验证；地图选点和路线距离显示已经在实际界面验证，真实设备的路线回放需要结合手机显示检查。默认位置为卫星图选定的固定坐标，不代表手机当前真实位置。

## 一键生成跑道（1.3）

可直接使用默认位置，或在「选择起点」模式单击地图选定其他跑道中心，然后输入周长（默认 400 米）和朝向（默认 0°，长轴朝北；90° 长轴朝东），点击「一键生成跑道」。若已有路线，则首次生成取已有路线首点为中心；重复生成保留相同中心。改变中心请重新地图选点或清空路线。不会默认用 Mac 位置作为跑道中心。

生成形状为两段直道和两个半圆，约 145 个路径点，自动开启循环。直道长度和半圆半径由周长按固定比例缩放，不保证与特定场地的跑道尺寸或车道一致；可调整中心、周长和角度使蓝线与地图跑道匹配。预期周长与实际点间距离有小量地球模型和离散误差，400 米测试误差小于 2 米。

点击「连接手机」「开始路线跑步」即可使用共享速度自动移动；用恢复按钮结束。

## 默认位置（1.3.1）

默认地图、WASD 起点、一键跑道中心为固定的默认位置（天安门广场），可以地图选点或输入坐标更改。手绘路线仍从你第一次点击的位置开始。

## 中国地图坐标校正（1.4）

本机 MapKit 中国底图由高德提供。地图选点、默认坐标、路线编辑均保留地图坐标，默认勾选「中国地图坐标校正（GCJ-02 → GPS）」，在发送给手机前转换为 WGS-84。固定点、WASD、手绘路线和生成跑道使用同一发送路径。界面分别显示地图坐标与实际发送的 GPS 坐标。

若使用中国境外底图或已输入 GPS/WGS-84 坐标，可关闭校正；全球边界判断采用近似范围，边界地区需要自行选择坐标模式。转换是本地近似算法，测试覆盖已知参考坐标与逆变换往返精度，不代表真实地图或 GPS 绝对精度。修复需在手机地图上确认。

默认位置地图坐标 39.904123 / 116.397682，转换后的 GPS 坐标约 39.902722 / 116.391441。此前版本把地图坐标直接当 GPS 发送，在中国地图下可能偏移数百米。
